# Teams Mode

CTF Arena v2 supports optional **Team-based competition modes**.

---

## 1. Organizing Competitors

- **Registration**: Competitors register as normal.
- **Team Creation**: Under the profile menu, any registered user can create a new team by assigning a unique name.
- **Joining a Team**: Users enter the target team's join credentials to associate their profile.

---

## 2. Scoreboard Calculations

When Team Mode is active:
- Standings sum the scores of all users associated with the team.
- Individual challenges solved by multiple members of the *same* team only award points to the team **once** (on the first solve timestamp).
- Leaderboard ranks display team names instead of individual player usernames.
