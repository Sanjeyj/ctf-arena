# ISO 27001 Compliance Mapping
# CTF Arena v1.0.0 — EthicBids Technologies™

This document maps the technical and security controls of CTF Arena v1.0.0 to the ISO/IEC 27001 Annex A controls.

---

## 1. Compliance Control Mapping

| ISO 27001 Control | Platform Control Implementation | Status |
|-------------------|---------------------------------|--------|
| **A.8.20 Network Security** | Internal Docker networks separate backend containers from frontend proxies. Frontend ports 80/443 only are exposed. | **Compliant** |
| **A.8.24 Use of Cryptography** | Session cookies are encrypted, and passwords hashed via `pbkdf2:sha256`. TLS 1.2+ configuration is enforced. | **Compliant** |
| **A.8.2 Access Control** | Unified Role-Based Access Control (RBAC) maps permissions explicitly to Admin, Moderator, and Participant roles. | **Compliant** |
| **A.8.12 Log Management** | Gunicorn and Nginx write detailed request and error trace logs to persistent storage volumes. | **Compliant** |
| **A.8.14 Redundancy of Info Processing** | Daily automated backups with compression and encryption, coupled with restore test scripts, satisfy data redundancy needs. | **Compliant** |
| **A.8.30 Security Testing in Dev** | CI/CD pipeline enforces a 1609-test regression gate and Trivy container scan before deployments. | **Compliant** |
