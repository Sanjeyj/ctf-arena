# Browser Support Matrix
# CTF Arena v1.0.0 — EthicBids Technologies™

This document defines the browser versions supported and tested for the glassmorphic user interface of CTF Arena v1.0.0.

---

## 1. Supported Browsers

| Browser | OS Platform | Minimum Version | Testing Status |
|---------|-------------|-----------------|----------------|
| **Google Chrome** | Windows, macOS, Linux | 110 | Fully Certified |
| **Mozilla Firefox** | Windows, macOS, Linux | 108 | Fully Certified |
| **Apple Safari** | macOS, iOS | 15.6 | Fully Certified |
| **Microsoft Edge** | Windows, macOS | 110 | Fully Certified |

---

## 2. Un-supported Engines

- **Internet Explorer**: All versions.
- **Legacy Edge** (pre-Chromium): Versions < 79.
- **Opera Mini**: Not supported due to CSS opacity/filter rendering constraints.

---

## 3. UI Features Verified

- CSS Variables / Custom Properties.
- CSS Backdrop Filters (glassmorphic blur effect).
- Grid and Flexbox responsive reflow layouts.
- SVG icons scaling.
