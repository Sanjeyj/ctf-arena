# Release Calendar & Cadence
# CTF Arena v1.0.0 — EthicBids Technologies™

This document defines the release cycle calendar for patches, minor enhancements, and major upgrades.

---

## 1. Release Types & Frequency

| Release Type | Version Target | Target Frequency | Description |
|--------------|----------------|------------------|-------------|
| **Patch Release** | `v1.0.x` | Bi-weekly / Ad-hoc | Bug fixes, dependency updates, and security hotfixes. No new features. |
| **Minor Release** | `v1.1.0` | Quarterly | Small functional enhancements, configuration additions, and minor optimizations. |
| **Major Release** | `v2.0.0` | Annually | Architectural upgrades, feature imports from the research lab, database refactoring. |

---

## 2. Release Windows

All standard releases occur on the following schedule:

* **Day of Week**: Tuesday
* **Time Window**: 06:00 – 08:00 UTC (off-peak hours)
* **Blackout Dates**: No releases during active wargaming campaigns, CTF events, or national holidays.
