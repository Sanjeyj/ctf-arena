# Support Guide — CTF Arena

If you need help or have questions about installing, configuring, or running CTF Arena, please read the channels below:

---

## 1. Questions and Discussions

For general queries, setup assistance, architecture discussions, or feature suggestions:
- Open a topic in the **[GitHub Discussions](https://github.com/Sanjeyj/ctf-arena/discussions)** tab of this repository.

---

## 2. Bug Reports and Feature Requests

If you encounter an issue or have a concrete feature suggestion:
- Search the existing issues list to see if it is already logged.
- If not, open a new issue using the appropriate template:
  - **[Bug Report](https://github.com/Sanjeyj/ctf-arena/issues/new?template=bug_report.md)**
  - **[Feature Request](https://github.com/Sanjeyj/ctf-arena/issues/new?template=feature_request.md)**

---

## 3. Security Concerns

If you discover a security vulnerability:
- **Do not open a public issue.**
- Follow the guidelines in our **[Security Policy](SECURITY.md)** and email us at `security@ctf-arena.example.com`.
