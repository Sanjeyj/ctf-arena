# Security Policy — CTF Arena

We take the security of CTF Arena seriously. Please read below for supported versions and reporting guidelines.

---

## Supported Versions

| Version | Supported |
|---------|-----------|
| **1.0.x** | Yes |
| **< 1.0.0** | No |

---

## Reporting a Vulnerability

1. **Do not create public GitHub issues** for security flaws.
2. Email security concerns directly to `security@ctf-arena.example.com`.
3. Provide details on reproducing the vulnerability, including sample payloads or requests.
4. We aim to acknowledge and respond to reports within **48 hours**.
