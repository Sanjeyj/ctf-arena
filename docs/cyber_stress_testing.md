# Strategic Cyber Stress Testing Guide

This guide describes stress testing methodologies for cyber resilience planning.

## Stress Scenario Lifecycle

1. **Drafting**: Defining candidate stress scenarios (e.g. ransomware disruption, region outage) with multipliers and duration parameters.
2. **Simulation**: Executing offline simulations with explicit seed constraints.
3. **Assessment**: Recording recovery time hours, checking risk appetite thresholds, and identifying breaches.
4. **Archiving**: Deactivating historical runs when threat topologies change.
