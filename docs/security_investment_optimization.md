# Security Investment Optimization

This guide outlines Return on Security Investment (ROSI) ranking logic.

## ROSI Calculation Model

```
ROSI = ((Expected Loss Reduction - Investment Cost) / Investment Cost) * 100
```

- ROSI measures the financial return generated by mitigating potential cyber-losses relative to the cost of deploying security controls.
- Priority rankings are calculated combining ROSI metrics and raw risk reduction.
- Division-by-zero protection prevents numerical errors for zero-cost options.
