# Platform Routing & Blueprint Directory

## 1. Blueprint Structure

All routes are versioned and logically grouped. Administrative routes reside under the `/admin` prefix.

---

## 2. Key Administrative Enclaves

### 2.1 Core & GRC Dashboards
- `/admin` — Main admin operations center.
- `/admin/mission-control` — System release baseline validation dashboard.
- `/admin/compliance` — Control frameworks compliance console.
- `/admin/resilience/vendors` — Third-party supplier registry.
- `/admin/risk-quantification` — Monte Carlo loss modeling simulation interface.

### 2.2 Security Fabrics (Batch D)
- `/admin/assurance` — Cyber trust overview and zero-trust decision logs.
- `/admin/validation-fabric` — Continuous validation dashboard with active campaigns and playbook indices.
- `/admin/exposure-fabric` — Exposed asset directories and attack path traverses.
- `/admin/operations-fabric` — Golden signals health, active incidents, telemetry metrics, and distributed tracing.

---

## 3. Participant Gateways
- `/login` — Participant authentication view.
- `/register` — Account registration gateway.
- `/challenges` — Active CTF challenge panel.
- `/scoreboard` — Real-time team standings and solves tracker.
