# Threat Prediction Engine Reference

This guide details predictions and forecasting indicators generated by the Threat Prediction Engine.

---

## 1. Predictive Inputs
The engine analyzes inputs from:
- **SOC**: Active alerts.
- **CTI**: Malware sample counts.
- **Research**: Active campaign reports.
- **Cyber Range**: Exercises completed.

---

## 2. API Endpoints

### Fetch Prediction Forecast
- **URL:** `/api/v1/predictions`
- **Method:** `GET`
- **Response (200 OK):**
  ```json
  {
    "predictions": {
      "forecasted_adversary": "APT28 / Cozy Bear",
      "trending_techniques": [
        "T1190 - Exploit Public-Facing Application"
      ],
      "high_risk_assets": [
        "Internal Active Directory Server"
      ],
      "confidence_percentage": 75.0,
      "alert_count_input": 5,
      "campaign_count_input": 2
    }
  }
  ```
