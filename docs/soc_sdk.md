# SOC Platform SDK & API Reference

Welcome to the CTF Arena Security Operations Center (SOC) API reference documentation. This platform facilitates simulated security operations, incident response, threat hunting, and threat intelligence.

---

## Base Path
All endpoints are relative to:
`/api/v1`

---

## 1. Indicator of Compromise (IOC) API

### List IOCs
Retrieves a list of Indicator of Compromise records.

- **URL:** `/iocs`
- **Method:** `GET`
- **Query Parameters:**
  - `org_id` (integer, optional): Filter by organization ID.
  - `type` (string, optional): Filter by type (`ip`, `domain`, `url`, `hash`, `email`).
  - `severity` (string, optional): Filter by severity (`info`, `low`, `medium`, `high`, `critical`).
- **Response (200 OK):**
  ```json
  {
    "count": 1,
    "iocs": [
      {
        "id": 1,
        "type": "ip",
        "value": "198.51.100.42",
        "severity": "high",
        "confidence": 90,
        "source": "OSINT",
        "tags": "c2,bruteforce",
        "geo_country": "US",
        "reputation_score": 15,
        "first_seen": "2026-07-02T12:00:00",
        "last_seen": "2026-07-02T12:30:00"
      }
    ]
  }
  ```

### Create IOC
Creates a new IOC record for tracking.

- **URL:** `/iocs`
- **Method:** `POST`
- **JSON Payload:**
  ```json
  {
    "type": "ip",
    "value": "198.51.100.99",
    "severity": "high",
    "confidence": 80,
    "source": "manual",
    "org_id": 1,
    "tags": "c2,apt29",
    "description": "Active C2 server"
  }
  ```
- **Response (210 Created):**
  ```json
  {
    "ioc": {
      "id": 2,
      "type": "ip",
      "value": "198.51.100.99",
      ...
    }
  }
  ```

### Enrich IOC
Triggers simulated threat intelligence enrichment (geo-location and reputation scores).

- **URL:** `/iocs/<ioc_id>/enrich`
- **Method:** `POST`
- **Response (200 OK):**
  ```json
  {
    "ioc_id": 1,
    "geo_country": "RU",
    "reputation_score": 15,
    "verdict": "malicious",
    "enriched_at": "2026-07-02T12:35:00"
  }
  ```

## 2. Alerts API

### List Alerts
Retrieves security alerts generated by the correlation engine.

- **URL:** `/alerts`
- **Method:** `GET`
- **Response (200 OK):**
  ```json
  {
    "count": 1,
    "alerts": [
      {
        "id": 1,
        "title": "Brute force attack on admin portal",
        "severity": "high",
        "status": "new",
        "event_type": "authentication",
        "source_ip": "198.51.100.42",
        "dest_ip": null,
        "mitre_tactic": "TA0001",
        "mitre_technique": "T1078 - Valid Accounts"
      }
    ]
  }
  ```

### Create Alert
- **URL:** `/alerts`
- **Method:** `POST`

### Triage Alert
Invokes the SOC AI service to analyze, map to MITRE ATT&CK, and recommend alert severity.
- **URL:** `/alerts/<alert_id>/triage`
- **Method:** `POST`
- **Response (200 OK):**
  ```json
  {
    "alert_id": 1,
    "original_severity": "medium",
    "recommended_severity": "high",
    "mitre_tactic": "TA0001",
    "mitre_technique": "T1078 - Valid Accounts",
    "analysis": "AI Triage Analysis for Alert #1..."
  }
  ```

## 3. Cases API

### List Cases
- **URL:** `/cases`
- **Method:** `GET`

### Create Case
- **URL:** `/cases`
- **Method:** `POST`

### Update Case & Transition Status
Applies state transitions (`open` -> `investigating` -> `contained` -> `resolved` -> `closed`).
- **URL:** `/cases/<case_id>`
- **Method:** `PATCH`
- **JSON Payload:**
  ```json
  {
    "status": "investigating",
    "note": "Beginning SSH log analysis."
  }
  ```

### Get Case Timeline
- **URL:** `/cases/<case_id>/timeline`
- **Method:** `GET`

## 4. Threat Hunting API

### Create Hunt
- **URL:** `/hunts`
- **Method:** `POST`

### Run Hunt
Triggers threat hunt scans (IOC, behavioral, MITRE, or anomaly).
- **URL:** `/hunts/<hunt_id>/run`
- **Method:** `POST`
- **JSON Payload (IOC Hunt):**
  ```json
  {
    "ioc_values": ["198.51.100.42"]
  }
  ```
- **JSON Payload (Behavioral Hunt):**
  ```json
  {
    "pattern": "brute.?force"
  }
  ```
