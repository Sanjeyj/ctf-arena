# Cyber Resilience Investment Planning

This guide describes strategic investment workflows.

## Workflow Lifecycle

- **Candidate Scenarios**: Resilience investment candidates are added to a strategic plan with assigned budgets.
- **Evaluation**: Each candidate is evaluated against risk reduction and resilience improvement index contributions.
- **Budget Compliance**: Prevents plan budget limits from being exceeded, rejecting negative allocations.
- **Human Approval**: Plan status is locked and approved items applied only under explicit administrator confirmation.
