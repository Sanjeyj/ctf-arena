# Security Policy | EthicBids Technologies™

## Vulnerability Disclosure
Report vulnerabilities to **security@ethicbids.app** with:
- Detailed description and reproduction steps
- Impact assessment (CVSS score if possible)
- Affected version and component

Response SLAs: Acknowledge within 24h | Triage within 72h | Critical CVE patch within 7 days.

## Supported Versions
| Version | Security Support |
|---|---|
| v1.0.0 | ✅ Active (until 2029-07-17) |
| < v1.0.0 | ❌ End of Life |

## Patch Process
Critical patches are released as `v1.0.x` hotfixes following ARB approval and full regression re-run.

## Hall of Fame
Responsible disclosures are credited in our security hall of fame at **ethicbids.app/security/hof**.
