# Analyst Assistance & Investigation Workflow — CDP v2.0

## 1. Natural Language Interface

SecOps analysts interact with autonomous agents using natural language:

```
[Analyst Question] ──> [NL Intent Parser] ──> [Agent Query Execution] ──> [Structured Narrative Response]
```

---

## 2. Assisted Analysis Actions

- **Incident Summarization**: Aggregates alerts, metrics, and affected nodes into markdown summary reports.
- **Timeline Explanation**: Builds chronological event timelines with explanations of lateral movement actions.
- **Playbook Recommendations**: Explains why a playbook is selected and outlines validation checks.
