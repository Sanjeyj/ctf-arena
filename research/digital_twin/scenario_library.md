# Cyber Scenario Library — CDP v2.0

## 1. Cataloged Simulation Scenarios

The platform maintains a library of pre-configured scenarios to evaluate organizational resilience:

```
[Scenario Catalog]
   ├── Ransomware Propagation Simulation
   └── Supply Chain Attestation Compromise
```

---

## 2. Scenario Specifications

### 2.1 Ransomware Propagation Simulation
- **Description**: Models active malware spreading across simulated network segments.
- **Hypothesis**: The simulation evaluates if segment segmentation policies isolate the infection under 3 hops.

### 2.2 Supply Chain Attestation Compromise
- **Description**: Models the injection of malicious updates through compromised software packages.
- **Hypothesis**: The simulation evaluates if compliance rules block unsigned updates.
