Investigation Guide:

When files are tracked in Git, deleting them or modifying them doesn't erase their history. Every commit ever made contains a snapshot of the files at that point in time.

🔍 Repository Auditing Commands:

Open your terminal in the ctf-arena project directory and use Git commands to query historical snapshots:

  • List commits with brief change log: git log --oneline
  • Inspect changes/diffs introduced by commits: git log -p
  • Search git history for occurrences of a specific string (like "FLAG" or "git_gud"): git log -S "FLAG" -p
  • Show details of a specific commit: git show <commit-hash>
