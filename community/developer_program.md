# Developer Program | EthicBids Technologies™ | Community

## Program Overview

The EthicBids Developer Program enables security developers, researchers, and CTF challenge authors to build on the Cyber Defense Platform using official APIs, SDKs, and tooling.

## Benefits

| Tier | Requirements | Benefits |
|---|---|---|
| **Community Developer** | Register at ethicbids.app/developers | API access, docs, forum support |
| **Verified Developer** | 1 published plugin or challenge | Co-marketing, early feature access, monthly office hours |
| **Elite Developer** | 5+ contributions, 100+ installs | Revenue sharing, dedicated support, EthicBids Certified badge |

## What You Can Build

- **Challenge Packages**: CTF challenges for the marketplace
- **Plugins**: Authentication providers, scoring hooks, notification integrations
- **Themes**: Custom UI themes for white-label deployments
- **API Clients**: Language-specific API wrappers (Python, Go, JS)
