# Ambassador Program | EthicBids Technologies™

## Overview

The EthicBids Ambassador Program recognizes passionate community members who evangelize the platform, grow local security communities, and represent EthicBids at events and online.

## Ambassador Responsibilities

- Host or co-organize at least 1 CTF event per quarter using EthicBids platform
- Create 1 piece of EthicBids-related content per month (blog, video, talk)
- Engage on Discord and social media channels weekly
- Provide product feedback through monthly Ambassador calls

## Benefits

| Benefit | Detail |
|---|---|
| **Free Professional License** | Full Professional tier for personal/community use |
| **EthicBids Swag Kit** | Exclusive branded merchandise |
| **Speaking Opportunities** | EthicBids-sponsored conference talk slots |
| **Revenue Referral** | 15% commission on referred paying customers |
| **Early Access** | Beta access to new features before public release |
| **Official Badge** | "EthicBids Ambassador" badge on profile and LinkedIn |

## Selection Criteria

- Active in security community (CTF, research, blogging, speaking)
- Positive standing on EthicBids platform
- Genuine enthusiasm for cybersecurity education
