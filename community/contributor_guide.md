# Contributor Guide | EthicBids Technologies™

## How to Contribute

We welcome contributions to:
- **Community Edition codebase** (open-core MIT license)
- **Challenge library** (via Marketplace submission)
- **Documentation** (guides, tutorials, translations)
- **Bug reports** (via GitHub Issues)

## Code Contribution Process

1. **Fork** the repository on GitHub
2. **Create a branch**: `git checkout -b feature/your-feature-name`
3. **Write tests** for any new functionality
4. **Run the test suite**: `pytest` (all 1,609 tests must pass)
5. **Submit a Pull Request** with a clear description
6. **Sign the CLA** (Contributor License Agreement) — required for all contributors
7. Await review from EthicBids maintainers (within 5 business days)

## Contribution Standards

- All code must pass `pylint` and `flake8` linting
- New features require unit tests with ≥ 80% coverage
- Documentation changes require spell-check
- No changes to production v1.0.0 modules without ARB approval

## Recognition

All contributors are listed in `CONTRIBUTORS.md`.  
Significant contributions earn the **EthicBids Contributor** badge on the community platform.
